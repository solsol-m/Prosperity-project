"Wealth Intelligence for a Sustainable Future"
Welcome to the official repository of Prosperity, an AI-driven financial platform developed during the SalamHack 2026 hackathon.
Prosperity is not just another expense tracker; it’s a Smart Financial Assistant designed to bridge the gap between daily spending and long-term financial security. We empower young users to take control of their wealth through data-driven insights and predictive AI.

# The Vision
Many young people struggle with "invisible expenses" and a lack of future financial clarity. Prosperity solves this by providing:
Real-time Analytics: Instant breakdown of every transaction.
AI Coach: Personalized, friendly financial advice based on actual spending habits.
Financial Time Machine: A forecasting engine that visualizes your savings 1 month and 1 year into the future based on today's decisions.

# Technical Architecture
The project is built with high engineering standards, ensuring scalability, security, and a seamless user experience.
Frontend – Developed by Malak El-Malahi
Focused on a modern, responsive UI/UX that supports both Arabic and English seamlessly:
React & Vite: For lightning-fast performance and a smooth Single Page Application (SPA) experience.
Tailwind CSS: For a clean, professional aesthetic aligned with the brand's identity.
Logic Integration: Custom frontend logic to handle predictive data visualization and AI interactions.
Backend – Developed by Anis Atallah
The robust backbone of the platform, ensuring data integrity and high performance:
.NET (C#): Chosen for its enterprise-grade security and reliability in handling financial data.
Web API: A sophisticated RESTful API bridge that connects the frontend to our logic and AI processing.

# Why Prosperity Stands Out?
Proactive Insights: Our system doesn't wait for you to ask; it uses AI to provide "Smart Nudges" to keep you on track.
Hybrid Precision: By combining .NET's stability with dynamic Frontend logic, we provide highly accurate financial forecasting.
Simplicity: We turned complex financial formulas into a simple, intuitive interface for everyone.
